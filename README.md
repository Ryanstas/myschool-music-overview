# My School Music

This project was developed privately using Bitbucket and cannot be shared publicly.

## Overview
My School Music is a full-stack web application designed to help schools manage music programs, students, and resources.

## Tech Stack
- React
- Node.js
- MySQL
- REST APIs

## Features
- User authentication and role-based access
- CRUD functionality for managing students and programs
- Responsive frontend built with React
- Backend API built with Node.js
